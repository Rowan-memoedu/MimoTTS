# MiMo TTS

Reusable local CLI and Python API for Xiaomi MiMo speech synthesis, with isolated comparison builds for WebLilt, KnowledgeClipper, SuperFreeTTS and OpenFocus.

Source: `D:\Projects\MimoTTS`. Runtime: `D:\AppData\MimoTTS`. Cache: `D:\Caches\MimoTTS`. Audio and test builds: `D:\Artifacts\MimoTTS`.

Credentials come from `MIMO_API_KEY` in the current process or Windows user environment. No keys, personal text, reference audio, runtime state or built artifacts belong in Git. Existing application defaults remain unchanged.

Official sources: [API guide](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/speech-synthesis), [MiMo Skills](https://github.com/XiaomiMiMo/MiMo-Skills/tree/main/skills/mimo-v2-5-tts).
